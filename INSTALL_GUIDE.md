# 📥 How to Install MoviePopcorn as an App

MoviePopcorn is a **Progressive Web App (PWA)**, which means you can install it on your device just like a regular app!

## 🖥️ Desktop (Windows/Mac/Linux)

### Chrome / Edge / Brave
1. Visit your MoviePopcorn site
2. Look for the **install icon** in the address bar (looks like a monitor with a down arrow)
3. Click it and select **"Install"**
4. **OR**: Click the three dots menu → **Cast, save, and share** → **Install MoviePopcorn**

### After Installation:
- ✅ Opens in its own window (no browser UI)
- ✅ Has its own taskbar/dock icon
- ✅ Works offline (cached content)
- ✅ Faster performance
- ✅ Feels like a native app

## 📱 Mobile (Android)

### Chrome
1. Visit your MoviePopcorn site
2. Tap the **three dots menu** (top right)
3. Tap **"Install app"** or **"Add to Home screen"**
4. Confirm installation

### Samsung Internet
1. Visit your MoviePopcorn site
2. Tap the **menu icon** (bottom right)
3. Tap **"Add page to"** → **"Home screen"**

### After Installation:
- ✅ App icon on home screen
- ✅ Opens in full-screen mode
- ✅ Works offline
- ✅ Push notifications (future feature)

## 📱 Mobile (iOS - iPhone/iPad)

### Safari
1. Visit your MoviePopcorn site
2. Tap the **Share button** (square with arrow pointing up)
3. Scroll down and tap **"Add to Home Screen"**
4. Tap **"Add"**

### After Installation:
- ✅ App icon on home screen
- ✅ Opens in full-screen mode
- ✅ Works offline
- ✅ Feels like a native iOS app

## 🔧 Troubleshooting

### Install Button Not Showing?
- Make sure you're using Chrome, Edge, or Brave
- Clear browser cache and reload
- Check if PWA is supported (most modern browsers support it)

### iOS Install Not Working?
- Must use Safari (Chrome on iOS doesn't support PWA install)
- Make sure you're on iOS 11.3 or later

### App Not Updating?
- PWA updates automatically in background
- Force refresh: Ctrl+F5 (desktop) or pull-to-refresh (mobile)

## 📊 Technical Details

MoviePopcorn uses:
- **Service Worker** - Caches assets for offline use
- **Web App Manifest** - Defines app metadata
- **Cache API** - Stores content locally
- **Background Sync** - Updates when online
